# Maskot Imp Ungu — 10 pose konten

Maskot orisinal (imp ungu bulat, tanduk emas, senyum gigi tajam, cakar kecil, sayap kelelawar,
ekor sekop), terinspirasi gaya referensi tapi bukan salinan karakter komik aslinya.
Semua gambar digambar dengan kode (SVG) — PNG 1024×1024 latar transparan, siap ditempel di konten.

| File | Pakai untuk |
|---|---|
| `out/01-selebrasi.png` | Pengumuman pencapaian, milestone, "berhasil!" |
| `out/02-menunjuk.png` | Menunjuk judul/teks di atas |
| `out/03-papan.png` | Papan kosong — tulis pesan/promo di atasnya |
| `out/04-halo.png` | Sapaan pembuka, perkenalan |
| `out/05-jempol.png` | Rekomendasi, testimoni, "mantap" |
| `out/06-umumkan.png` | Pengumuman, info penting, promo |
| `out/07-mikir.png` | Tips, pertanyaan, kuis |
| `out/08-kaget.png` | Fakta mengejutkan, diskon besar |
| `out/09-hadiah.png` | Giveaway, bonus, hadiah |
| `out/10-ngintip.png` | Ditempel di tepi bawah frame (mengintip) |

Render ulang: `node build.mjs` (butuh Playwright + Chromium). Warna ada di objek `C`,
pose di daftar `POSES` di `build.mjs`.
